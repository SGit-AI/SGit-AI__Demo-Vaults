Demo Vaults

catalogue: inlined fallback

Every vault listed here is read-only by construction: the page publishes the read key, which is one-way derived and can never be turned back into write access. Write keys are escrowed out-of-band and never appear on this site or in its git history. A vault marked frozen has a lost write key: readable forever, never correctable. Archives (vault.zip) contain only the encrypted object store — clone this site's repo and you can redeploy every vault to any server. Part of sgit.ai.
